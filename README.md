<br/>

A desktop attendance system that identifies people through face recognition and records attendance automatically, built with a from-scratch LBPH recognizer rather than a black-box library.

| Attribute | Details |
|:--|:--|
| **Stack** | Java · OpenCV · Custom LBPH Recognizer · SQLite · Swing |
| **Scale** | Multi-user face enrolment with persistent attendance records |
| **Performance** | Real-time face detection and recognition from a live camera feed |
| **Security** | Local-only data storage, no third-party cloud processing of biometric data |
| **Impact** | Replaces manual roll-calls with fast, contactless, automated attendance |
| **Repository** | [![Repo](https://img.shields.io/badge/View_Repository-7c3aed?style=flat-square&logo=github)](https://github.com/Prakash2906/face-recognition-attendance) |
